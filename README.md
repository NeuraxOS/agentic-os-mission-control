## 🌌 Bienvenue dans AGENTIC OS

**AGENTIC OS V3.0 — Mission Control** est une application de bureau Windows conçue pour réunir l'intelligence artificielle, les outils intelligents et la gestion du système au sein d'une interface unique.

Avec son environnement futuriste, AGENTIC OS propose une nouvelle manière d'interagir avec les technologies d'intelligence artificielle.

L'objectif est de créer un espace de travail centralisé, intuitif et évolutif.

**Une interface. Plusieurs systèmes intelligents. Une expérience unifiée.**

Un projet imaginé et développé sous l'identité **NeuraxOS**.

## ✨ Fonctionnalités principales

### 🧠 JARVIS — Assistant intelligent

Une interface d'assistant centralisée, conçue pour faciliter les interactions avec les fonctionnalités d'intelligence artificielle et les outils connectés.

Un espace permettant d'explorer et de gérer des flux de travail impliquant plusieurs agents intelligents.

Un environnement expérimental dédié à l'exploration d'améliorations, de propositions et de nouvelles possibilités de développement.

## 📦 Installation

1. Accédez à la section **Releases** du dépôt GitHub.
2. Téléchargez l'installateur Windows d'une version vérifiée et disponible.
3. Vérifiez son empreinte SHA-256.
4. Consultez les éventuels avertissements de sécurité Windows.
5. Lancez l'installateur et suivez les instructions affichées.

### 🔐 Vérification du téléchargement

Dans PowerShell, depuis le dossier contenant l'installateur :

```powershell
Get-FileHash -LiteralPath '.\AGENTIC OS V3.0.exe' -Algorithm SHA256
```

Comparez l'empreinte obtenue avec celle publiée pour la version téléchargée.

**Important :** l'installateur précédemment analysé utilise l'identité d'origine d'AGENTIC OS. Si une version de l'application est déjà installée, vérifiez les conditions de mise à jour avant de continuer.
