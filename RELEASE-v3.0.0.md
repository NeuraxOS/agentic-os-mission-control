# AGENTIC OS V3.0 — Windows

**Version prévue** : `v3.0.0`

Cette version Windows x64 réunit Mission Control, JARVIS, Skills, Memory, Security Center, JARVIS Vision, Multi-Agent Brain et Self-Improvement Lab. La présence des modules a été vérifiée dans le paquet.

## Téléchargement et installation

Une fois publiée, téléchargez `AGENTIC OS V3.0.exe` depuis les fichiers de cette version. Vérifiez son SHA-256, puis suivez l’assistant Windows. Une installation utilisant déjà l’identité AGENTIC OS d’origine peut être concernée par la mise à jour.

- **Fichier** : `AGENTIC OS V3.0.exe`
- **Taille** : 227 176 219 octets
- **SHA-256** : `F9CAD341F86D9848FFD43DED7B685F6EF003CA4E9977BA2E41CCE534BA215202`
- **Signature** : l’EXE n’est pas signé. Windows peut afficher un avertissement de sécurité.

## Limitations connues

Les tests d’installation sur une machine vierge et les prérequis Windows minimaux restent à confirmer. La voix Hugo, Whisper et le fonctionnement du microphone ne sont pas annoncés pour cette version.

Les notices Electron, Chromium et celles des dépendances présentes dans le paquet restent applicables. La validation de redistribution est en attente.
